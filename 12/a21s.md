### Pre-installation:

* Must have Latest OneUI 4.1 before the install
* Must have an unlocked bootloader
* Recovery (from download page, recovery button)
* Optional gapps (from download page, gapps button)
* Odin3 [Download](https://undocumented.software/Odin_3.13.1.zip)

### First time installation (clean flash):

* Remove all Google accounts from your device to avoid FRP (Factory reset protection).
* Backup Data if needed and plug your device into a computer.
* Power off the phone, then enter Download Mode using Volume Down + Volume Up and enter Odin3.
* Go to options and uncheck auto reboot.
* In Odin3, select the AP slot and input the recovery file (Read the next step before installing).
* After the flash is done, hold Volume Down + Power till screen goes black then Volume Up + Power until in recovery.
* In recovery, click Apply Update, then Apply from ADB.
* Press right click in your adb tools folder.
* Then put this command on your PC and adapt as needed (grab the file with the mouse in the terminal) to install the crDroid rom:

```
adb sideload crdroid.zip
```
* After it's done, do the same steps to install any additional packages (gapps).
* In crDroid recovery, select Factory reset, then Format data/factory reset.
* Then Reboot and enjoy.

### Update installation:

* Go to the system updater in the Settings app, and download the new update.
* After the download is done, the update will be installed automatically. 
* Reboot.

NOTE: If after OTA, some additional packages you had installed (e.g Magisk) are not there anymore, reflash them in recovery with ADB.
