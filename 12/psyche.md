### Pre-installation:

* Optional OrangeFox Recovery- (get it on [R11.3](https://github.com/Verevka/OrangeFox-Builder/releases/tag/21561224358)
* Optional gapps (from download page, gapps button)
* Optional KernelSU Next apk (get it on [v1.1.1](https://github.com/KernelSU-Next/KernelSU-Next/releases/tag/v1.1.1) from GitHub - click "show all assets" to see the apk)


### First time installation (clean flash):

* Backup your data to PC, OTG flash drive
* Make use of recovery (from download page, recovery button - I'm using OFox)
* Boot recovery
* Flash crDroid 12.x (toggle auto flash twrp)
* Reboot recovery
* (optional) flash Gapps (no auto toggle needed)
* (optional) flash Magisk (no auto toggle needed) (but ROM is kSU ready so ... )
* (optional) flash DFE
* Format
* Boot system


### Update installation: (if already on cr12)

* Follow same install steps but skip format
