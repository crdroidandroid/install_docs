### Pre-installation:

* Device: Redmi 15 / POCO M7 (creek)
* Make sure the bootloader is unlocked.
* Download the latest crDroid 13.1 Vanilla ROM:
  [crDroid 13.1 ROM](https://pixeldrain.com/u/tBo9hEww)
* Download the provided recovery:
  [Recovery](https://drive.google.com/uc?id=1ozAhfOAPtsHtVEBesWqhzKxIaIdRqiuD&export=download)
* This is a Vanilla build. Google Apps are not included.
* Back up all important data before proceeding.
* Formatting data will erase internal storage and user data.

### First time installation (clean flash):

1. Download the ROM ZIP and provided recovery.
2. Boot the device into the provided recovery.
3. Select Install and flash the crDroid ROM ZIP.
4. After flashing is complete, return to the recovery main menu.
5. Select Format Data.
6. Type `yes` to confirm formatting.
7. Wait until formatting is complete.
8. Select Reboot System.
9. Wait for the first boot to complete.

### Update installation:

* Dirty flash/update installation has not been validated for this initial release.
* A clean flash is recommended.
