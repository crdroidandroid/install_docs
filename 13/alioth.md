### Pre-installation:

* Firmware OS1.0.2.0.TKHMIXM mandatory (from download page, firmware button)
* Optional crdroid gapps (from download page, gapps button)
* Kernel comes without root/ksu integration. If root needed rom is being tested with E404 (RE404-POCO_F3-BPF-261025-1503) kernel and KowSU_v3.3.0-39-g36adc22d_32640-release


### First time installation (clean flash):

* Backup your data to PC, OTG flash drive
* Make use of build-in crdroid recovery (OFox A17 not being tested yet)
* Boot recovery
* Flash OS1.0.2.0.TKHMIXM (skip if you are already on this version)
* Flash crDroid 13.x
* Reboot recovery when asked
* (optional) sideload Gapps
* Format
* Boot system


### Update installation: (if already on cr13)

* Follow same install steps but skip format
