# 📱 Installation Guide for crDroid on Samsung Galaxy A71 (SM-A715F)

---

## 🧰 Requirements

- Unlocked bootloader
- Custom recovery (Lineage Recovery or TWRP recommended)
- A computer with ADB & Fastboot installed
- Backup your data – clean flash will erase everything

---

## 📦 Files to Download

- crDroid ROM: `crDroidAndroid-15.0-20250530-a71-v11.5-signed.zip`
- GApps package (optional): [MindTheGApps](https://mindthegapps.org/) or [NikGApps](https://nikgapps.com/)
- TWRP or Lineage Recovery image for A71

---

## ⚙️ Installation Steps

### 1️⃣ Boot into recovery mode

- Power off the device  
- Press **Volume Up + Power** to enter recovery

---

### 2️⃣ Format data (recommended for clean flash)

- In recovery, go to `Wipe > Format Data`
- Type `yes` and confirm

---

### 3️⃣ Flash crDroid ROM

- Tap `Install`
- Select the crDroid `.zip` and swipe to flash
- (Optional) Flash GApps right after

---

### 4️⃣ Reboot to system

- Tap `Reboot > System`
- Wait for first boot (can take a few minutes)

---

## ⚠️ Notes

- If internal storage doesn’t show up, perform `Format Data` again
- If using Lineage Recovery, use `adb sideload` or external SD card
- No need to flash recovery again if it’s already installed
