# Installing crDroid on Samsung Galaxy A71

## Prerequisites

- Unlocked bootloader
- Latest custom recovery (Lineage Recovery or TWRP)
- Backup your data (internal storage will be wiped)

## Instructions

1. Boot to recovery
2. Format data (if coming from another ROM)
3. Wipe system, data, cache and vendor
4. Flash crDroid ROM zip
5. (Optional) Flash GApps (if not included)
6. Reboot and enjoy

## Notes

- Recommended recovery: Lineage Recovery or TWRP
- SafetyNet may require additional modules (e.g., Magisk + DenyList)
